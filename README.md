#Calculations Using JavaScript Functions

#Description

A simple calculator webpage that performs different mathematical operations using JavaScript functions.

#Technologies Used

* HTML
* CSS
* JavaScript

#Operations

* Addition
* Multiplication
* Subtraction
* Division
* Modulus

#Concepts Used

* JavaScript Functions
* User Input
* parseInt()
* Arithmetic Operators
* DOM Manipulation
* HTML Input Fields
* Button Events

#Purpose

To practice creating JavaScript functions and performing mathematical calculations using user-provided values.
